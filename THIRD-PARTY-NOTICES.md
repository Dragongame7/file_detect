# Third-party components

Folder Sentinelの配布物には、以下のコンポーネントと、その依存コンポーネントが含まれます。各コンポーネントのライセンス・通知ファイルは配布物中の`licenses`フォルダ、および公式リポジトリを参照してください。

| Component | Source |
| --- | --- |
| .NET runtime / Windows Desktop | https://github.com/dotnet/runtime / https://github.com/dotnet/wpf |
| Windows App SDK | https://github.com/microsoft/WindowsAppSDK |
| CommunityToolkit.Mvvm | https://github.com/CommunityToolkit/dotnet |
| Microsoft.Data.Sqlite | https://github.com/dotnet/efcore |
| SQLitePCLRaw | https://github.com/ericsink/SQLitePCL.raw |
| SQLite | https://sqlite.org/copyright.html |

NuGetで解決された正確な依存バージョンは、ソースの`obj/project.assets.json`と、配布物の`FolderSentinel.deps.json`で確認できます。
